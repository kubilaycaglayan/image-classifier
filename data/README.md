# Dataset

The current educational dataset is sourced from public GitHub image collections.
The images are small RGB JPEGs, split into 15 training images and 5 validation
images per class. The exact source repository, source path, declared repository
license status, split, and dimensions for every image are recorded in
`provenance.csv`.

Review each upstream repository's terms before redistributing this dataset.
Some repositories do not declare a license for their image assets; those rows
are explicitly marked `UNSPECIFIED_UPSTREAM_LICENSE` rather than being treated
as freely licensed. The provenance file is part of the dataset and should be
kept with it.
