# Image Classifier

Educational PyTorch project for classifying images of bottles, wristwatches,
and pencils.

## Project layout

- `src/` — reusable Python implementation
- `notebooks/` — exploration, visualization, and experiments
- `data/raw/` — original, unchanged dataset files
- `data/processed/` — generated or transformed dataset files

The model and training pipeline will be added in later steps.
